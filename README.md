# jorgebg90.github.io

Portada estática de [jblueprint.dev](https://jblueprint.dev/) con acceso directo
al blog (`/blog/`) y a Vigo Bus Navigator (`/vigo-bus-navigator/`).

- Español: `index.html` (`/`).
- Inglés: `en/index.html` (`/en/`).
- Estilos compartidos y adaptados a móvil: `styles.css`.

No requiere compilación ni dependencias. Para previsualizarla localmente,
ejecuta `python3 -m http.server 8000` y abre `http://localhost:8000`.
Los proyectos enlazados se publican por separado y no se sirven en esta
previsualización local.
